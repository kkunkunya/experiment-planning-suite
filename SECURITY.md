# Security Policy

Report security issues privately to the repository owner.

Do not open public issues that contain secrets, customer files, private endpoints, generated logs, or unpublished research data.

## Secret Policy

This repository must not contain:

- API keys, tokens, cookies, or private keys
- private project materials or customer materials
- generated experiment logs with sensitive paths or data
- local runtime cache files

Users should configure credentials locally and keep them outside git.
